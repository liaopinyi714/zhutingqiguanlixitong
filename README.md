# 聆序 · 助听器客户管理

面向助听器门店的客户与服务档案工作台。正式版使用 Cloudflare Workers、D1、私有 R2 与 Access 员工身份验证；业务功能保持与已验收 Demo 一致。正式数据库从空库开始，本地演示资料另行隔离。

**首次部署推荐按 [Cloudflare 网页操作指南](docs/DEPLOYMENT-GUI.md) 操作。** 你只需使用 Cloudflare 和 GitHub 网站；Cloudflare 在云端自动构建、建表和发布，不需要在自己的电脑运行命令。另有 [命令行部署指南](docs/DEPLOYMENT.md) 和 [备份恢复指南](docs/BACKUP.md)。R2 超免费额度会按量计费，中国大陆连接需要实测。

## 已实现

- 客户档案新建、编辑、按服务阶段筛选。首页中央搜索框、侧栏搜索框及 `Ctrl/⌘ + K` 可跨客户资料、检查结论、设备和随访记录检索，并直接打开档案。
- 同页建档：一次录入客户基本资料、住址、其他联系人及其电话，并可同时录入听力检查与听力图、验配和首次随访。整份资料一次保存。
- 客户概览可逐项点击铅笔修改基本资料；检查、验配和随访记录可打开原内容编辑。
- 纯音听力图：125–8000 Hz，左右耳气导、骨导、逐点掩蔽、无反应、四频平均听阈、历史对比、打印/PDF。
- 言语测听及其他检查结果文本、结论与建议。
- 设备品牌型号、左右耳、序列号、成交金额、保修期和验配调试说明。
- 门店自建助听器型号字典：品牌 → 系列 → 型号；店主可添加、改名与停用，录入验配时逐级选择。旧验配记录保留保存时的名称。
- 随访预约、逾期提示、完成结果及服务历史。
- PDF/JPG/PNG 私有附件上传、鉴权下载、删除与恢复（单文件 10 MB）。
- 客户来源、年龄、阶段、随访类型与完成情况统计。
- 保修到期提醒：统计页列出已到期及未来 90 天内到期的设备，可直接打开客户档案。
- 客户、检查、验配、随访及报告附件支持删除和恢复；删除保留审计痕迹，已删除资料不出现在普通查询中。店主可在客户列表恢复档案，服务记录在客户详情页恢复。删除后保留 30 天；每日定时清理到期记录及 R2 附件文件。
- 店主、验配师、前台三种角色；Access 验证员工邮箱，服务端分配门店与权限，审计记录具体员工身份。
- 店主 JSON 导出：包含档案、检查、验配、随访、型号字典、附件目录和审计。附件文件需单独下载。

## 本地演示

需要 Node.js 24 和 pnpm 11。Windows、macOS、Linux 均可。

```sh
git clone https://github.com/liaopinyi714/zhutingqiguanlixitong.git
cd zhutingqiguanlixitong
pnpm install
pnpm build
pnpm db:local
pnpm dev:api
```

打开 http://127.0.0.1:8787 ，选择演示角色进入。上述本地命令显式使用 `wrangler.demo.jsonc`，含 12 份虚构客户。D1 和 R2 使用 Cloudflare 本地模拟器，数据在 `.wrangler/state/`，刷新页面或重启服务不会清空。不要将该目录提交 Git。

开发时保持 `pnpm dev:api` 运行，再开一个终端执行 `pnpm dev`，访问 http://127.0.0.1:5173 。Vite 会将 `/api` 代理到 8787。

```sh
pnpm test   # 听力规则、API 权限、门店隔离与持久化测试
pnpm build  # TypeScript 检查与生产构建
```

## 体验顺序

1. 选择店主进入，从首页醒目的搜索框查找客户；可输入姓名、电话、设备型号或检查与随访内容，也可按 `Ctrl/⌘ + K`。
2. 打开陈淑华的档案，查看听力图、设备和随访。
3. 在门店设置中添加一个虚构品牌、系列和型号；从客户列表新建一位虚构客户，在同一页填写住址、其他联系人电话、听力图、验配和首次随访。
4. 打开该客户的概览，逐项修改基本资料；在检查、验配和随访页体验编辑、删除与恢复。到统计页查看保修到期名单。
5. 回到随访页，填写联系结果；刷新后再次查看档案。上传一份虚构报告，验证下载、删除与恢复。

## 项目结构

```text
src/                 React 工作台、SVG 听力图、响应式样式
server/domain.ts     听力数据规则、校验、角色能力
server/index.ts      Hono HTTP 接口及数据库/文件调用
server/auth.ts       Access JWT 验证与员工授权
server/retention.ts  30 天恢复期与到期清理
migrations/          本地演示迁移（含虚构数据，禁止用于正式库）
migrations-production/ 正式空库建表和后续迁移
scripts/             部署配置、员工 Secret 上传、完整备份
tests/               业务和接口测试
docs/                部署、迁移及版本边界
wrangler.jsonc       Cloudflare 正式配置（默认禁止演示登录）
wrangler.demo.jsonc  仅本机演示配置
```

前端通过 HTTP JSON 接口与后端通信，SQL 数据和文件分别保存。认证模块与业务路由分离；更换服务商时可复用前端、业务校验与大部分路由，并适配数据库、文件存储和身份提供商。迁移到 PostgreSQL 需要转换建表和部分 SQL，不能直接执行 D1 的 SQLite 迁移文件。

## 正式部署与边界

默认 `wrangler.jsonc` 为正式配置。补齐资源 ID 和 Access 后，依次执行 `pnpm db:production`、`pnpm staff:upload`、`pnpm run deploy`。公网请求不接受 Demo 角色登录或旧 Demo cookie，即使误设 `DEMO_MODE=true` 也不能在公网使用演示登录。演示模式只允许 localhost、127.0.0.1 和 ::1。

登录由 Access 负责，无公开注册或本地密码。员工配置通过管理员 Secret 管理。代码已具备部署所需的认证、隔离、安全响应头、请求体限制、正式迁移和备份工具；仍需在实际 Cloudflare 账户核对 Access、额度、网络及恢复能力。备份脚本是手动工具，没有偷偷设置自动备份或自动清除本地文件。

本轮没有增加儿童专门验配流程、仪器自动导入、结构化言语测听/声导抗、自动消息通知、多门店切换界面、历史资料批量导入或字段级修订历史。编辑记录具体操作人，但不保存修改前的全部字段。页面全量 JSON 导出不含报告文件，完整备份应使用备份工具。

听力图与平均值用于记录展示，不自动诊断疾病、不自动给出选配处方。内置设备名称仅作示例。

详见 [部署指南](docs/DEPLOYMENT.md) 和 [设计与迁移说明](docs/ARCHITECTURE.md)。
